# skyrush-game

**SkyRush** — a 2D jetpack shooter (HTML5) for CrazyGames, in the style of
Mini Militia: fast ground movement, gun pick-ups, free-for-all matches with
bots that play like real players, 4.5-minute matches, and a simple classic
home screen (large Play button, corner Settings, separate Store).

## Run

The repo is a single `index.html` — no build step.

Open `index.html` in a browser, or serve the folder with any static server, for example:

```bash
python3 -m http.server
```

Then open http://localhost:8000/
